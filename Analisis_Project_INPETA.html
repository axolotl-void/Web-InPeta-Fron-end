📌 Apa Ini?

INPETA = Sistem Informasi Terintegrasi Peternakan Aceh

Website portal informasi peternakan untuk Provinsi Aceh yang menampilkan data wilayah, populasi ternak, fasilitas peternakan (Puskeswan, Pasar, dll), dan peta interaktif.

🏗️ Arsitektur Sistem

Arsitektur Fullstack — Frontend dan Backend terpisah, berkomunikasi lewat REST API.

🖥️ Fitur Frontend (Public / Pengunjung)

1. Landing Page /

  • Hero Section — judul, deskripsi + statistik angka
  • Tentang — penjelasan tentang InPETA
  • Fitur Unggulan — showcase fitur dengan ikon
  • Berita & Publikasi — 3 berita terbaru
  • FAQ — pertanyaan umum
  • Footer — kontak, alamat, sosial media
  • Navbar dinamis — menu dari database (CMS)

2. Peta Wilayah /peta

  • Peta interaktif Leaflet — visualisasi wilayah Aceh
  • GeoJSON polygon — batas wilayah berwarna
  • Marker fasilitas — titik lokasi Puskeswan, Pasar, dll
  • Clustering marker — group marker berdekatan
  • Layer manager — toggle layer on/off
  • Filter sidebar — filter kategori & wilayah
  • Stat cards — ringkasan populasi ternak

3. Halaman Puskeswan /puskeswan

  • Daftar lokasi pos kesehatan hewan

4. Halaman Berita /berita

  • Daftar semua berita & publikasi peternakan

🔐 Fitur Backend / Admin Dashboard /dashboard

Login dulu via /login → masuk ke dashboard admin.

#ModulFitur
1 CMS Landing Page CRUD: Hero Content, Logo, Statistik, Menu Navbar (+ sub-menu), Tentang, Fitur Unggulan, FAQ, Berita (+ upload gambar), Footer (+ sosmed)
2 Manajemen Wilayah CRUD wilayah (Kabupaten/Kecamatan), kelola populasi ternak per wilayah per tahun (sapi, kambing, ayam, kerbau), set warna area peta
3 Manajemen Fasilitas CRUD fasilitas (Puskeswan, Pasar, Koordinat), input lat/long + alamat, assign ke wilayah
4 Manajemen Admin Tambah/edit/hapus user admin & staff, set role (ADMIN / STAFF), aktifkan/nonaktifkan akun
5 Pengaturan Akun Edit profil (nama, email), upload avatar, ganti password, toggle dark mode
6 API Key Management Generate API key (inpeta_xxx...), toggle aktif/nonaktif, hapus — untuk akses data pihak ketiga
7 Export Data Export data fasilitas & populasi ke file CSV

📊 Ringkasan

INPETA adalah portal web GIS peternakan Aceh dengan CMS admin lengkap. Pengunjung bisa lihat peta interaktif, data populasi ternak, dan berita. Admin bisa kelola semua konten web tanpa coding — dari hero section sampai footer, termasuk data wilayah, fasilitas, dan populasi ternak.
